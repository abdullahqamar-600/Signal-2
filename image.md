`summit-variations/assets/photos/` so the project stays self-contained.
Optimize for web (resize to ~2400px wide max, compress to ~300–500 KB) — the
originals are full-resolution camera output.

```
summit-variations/
└── assets/
    └── photos/          ← copy chosen images here, web-optimized
```

Reference from HTML as `assets/photos/<filename>.jpg`.

## Visual notes for future sessions

- **Two visual eras:**
  - *Convention 2026 ("TRANSFORM")* — darker, more cinematic main-stage
    shots; deep blues and magentas; high-contrast theatrical lighting;
    polished panel-and-fireside production. Reads as "current Signal."
  - *Owner Summit 2024* — brighter rooms, saturated Signal Blue + orange
    logo accents, daylit outdoor candids, pumpkins-on-stage October mood.
    Reads as "warmer, more conversational."
  - **Avoid mixing the two within a single hero or grid section** unless
    the layout provides a clear buffer (typography, whitespace, or a rule).
    They sit in different lighting temperatures.
- **Palette match:** Both sets carry saturated Signal Blue with orange/sunburst
  accents — they slot naturally into the 70/20/10 palette without color
  correction.
- **Light:** The outdoor candids (2024) are golden hour (warm, soft). Indoor
  2024 sessions are overhead LED — cooler, more clinical. 2026 stage shots
  are dim/theatrical with hard key lights — moodiest of the three. Mix with
  care.
- **TRANSFORM theme treatment:** The Convention 2026 stage carries large
  type ("TRAN…", "TRANSFORM"), Owners shields, and sunburst accents — these
  duplicate the brand language already on the variations, so cropping out
  the screen text is rarely necessary.
- **Faces:** Many shots include identifiable attendees with name tags. For
  early/internal mockups this is fine; for any external use confirm release
  permissions before publishing.
- **Pumpkins on stage** in a few 2024 shots (e.g. `-1144`, `-1681`) tie
  naturally to the 2026 event's October dates — lean into these where
  October mood is wanted.
- **Aspect ratios:** Most are 3:2 (landscape) or 2:3 (portrait); the
  `OwnersSummit_10.2024_-36.jpg` panorama is much wider (~3:1) — best used
  as a true banner. Convention 2026 stage shots (`-0700`, `-0727`, `-0732`,
  `-0738`, `-1410`) are 3:2 landscape and crop well to wide 21:9 banners.
- **Activity / off-site:** `Convention2026-0181.jpg` is currently the only
  off-site / non-session photo in the catalog (tropical mini-golf). Use it
  sparingly — there is no second activity shot to pair it with.
